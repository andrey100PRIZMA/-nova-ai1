FAQ

Частые вопросы

NOVA уже может менять файлы на моём ПК?

Нет. Это функция будущего Windows-приложения. Сайт не получает доступ к файлам компьютера.

Будет ли NOVA бесплатной?

Локальные модели можно запускать без платы за каждый запрос. Нужны совместимое устройство и место для загрузки модели. Облачные сервисы могут иметь отдельную стоимость и лимиты.

Сможет ли она загружать проекты на GitHub?

Это можно реализовать в дальнейшем. Для публикации понадобится подключение к GitHub и подтверждение пользователя перед отправкой.

Когда выйдет приложение?
